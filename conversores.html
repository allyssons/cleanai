Conversores e calculadoras grátis

Converta unidades comuns e resolva cálculos do dia a dia. Os resultados aparecem no aparelho, sem cadastro; cada ferramenta mostra a fórmula usada para você conferir.

PESO

Libras para quilogramas

Use esta conversão para comparar peso em libras (lb) com o sistema métrico.

Digite um valor para converter.

Fórmula: libras × 0,45359237 = quilogramas. O fator usa a definição internacional da libra.

DISTÂNCIA

Milhas para quilômetros

Converta distâncias de viagens, corridas e mapas para quilômetros.

Digite um valor para converter.

Fórmula: milhas × 1,609344 = quilômetros. Uma milha internacional corresponde exatamente a 1,609344 km.

DISTÂNCIA

Quilômetros para milhas

Veja a distância equivalente em milhas sem fazer a conta manualmente.

Digite um valor para converter.

Fórmula: quilômetros ÷ 1,609344 = milhas. O resultado é exibido com até oito casas decimais.

COMPRIMENTO

Metros para centímetros

Transforme medidas em metros para centímetros, mantendo a relação decimal.

Digite um valor para converter.

Fórmula: metros × 100 = centímetros. Por exemplo, 1,75 m corresponde a 175 cm.

PROPORÇÃO

Regra de três direta

Se A corresponde a B, descubra quanto C corresponde na mesma proporção.

Preencha os três valores.

Cálculo: X = (B × C) ÷ A. Esta ferramenta resolve proporções diretas; não interpreta relações inversamente proporcionais.

PORCENTAGEM

Variação percentual

Compare um valor inicial e um valor final para calcular o aumento ou a redução em porcentagem.

Preencha os dois valores.

Fórmula: (valor final − valor inicial) ÷ valor inicial × 100. O valor inicial precisa ser diferente de zero.

Como conferir as conversões

As conversões usam fatores definidos para as unidades internacionais. A calculadora mantém a precisão durante a conta e arredonda a apresentação para no máximo oito casas decimais; isso facilita a leitura sem ocultar a fórmula.

  • Libras para quilogramas: multiplique o peso em libras por 0,45359237.
  • Milhas para quilômetros: multiplique milhas por 1,609344. Para voltar de quilômetros a milhas, divida pelo mesmo fator.
  • Metros para centímetros: multiplique metros por 100.
  • Regra de três direta: quando A/B = C/X, calcule X = (B × C)/A.
  • Variação percentual: subtraia o valor inicial do final, divida pelo inicial e multiplique por 100. Resultado negativo indica redução.

Seus valores ficam privados

Os cálculos são executados por JavaScript nesta página. Os números digitados não são enviados para um servidor nem armazenados pelo site. Se compartilhar o resultado, confira se as unidades e casas decimais fazem sentido para o seu uso.

Dúvidas comuns

Como digitar números decimais?

Você pode usar vírgula ou ponto como separador decimal. Em números com separador de milhar no padrão brasileiro, digite, por exemplo, 1.234,5. O resultado aparece formatado em português do Brasil.

Por que alguns resultados têm menos casas decimais?

Zeros no fim são omitidos para facilitar a leitura. A apresentação usa no máximo oito casas decimais; valores muito pequenos podem ser arredondados visualmente.

A regra de três também calcula proporção inversa?

Não nesta versão. O resultado considera proporção direta: quando A aumenta, B e X variam na mesma direção. Use outra fórmula quando a relação entre as grandezas for inversa.

    What information can a video contain?

    A video file may store a title, author, date, comment, location, editing app, and other information inside the MP4 or QuickTime MOV container. The tool checks for some common fields and shows only the type of information found, not its value.

    MP4 and MOV files up to 200 MB are supported. MKV, WebM, AVI, fragmented files, and unusual structures are not supported yet. A large metadata block or a structure that cannot be inspected safely may be rejected.

    How to use the cleaner

    1. Choose an MP4 or MOV video up to 200 MB.
    2. Select “Analyze video” to see recognized field categories. Field values are not shown.
    3. If a clean copy is available, download it and test playback in the app where you plan to use it.
    4. Compare the result with your original and keep the original file.

    If no common fields are recognized, that does not prove the video contains no metadata. Unknown blocks may remain, and a recognizable C2PA indicator blocks cleanup.

    How the copy is created

    When compatible fields are found, the tool replaces those blocks with neutral data of the same size. The encoded audio and video do not need to be re-compressed, and internal file offsets are preserved. The tool downloads a new copy; your original remains unchanged.

    Only field types recognized by this version are cleaned. Proprietary metadata, subtitles, chapters, extra tracks, thumbnails, visible names inside the video, and information outside the inspected blocks may remain. Check that the copy opens before sharing.

    Example: a video exported from an editor

    A MOV file may include fields such as title, author, location, and creation or modification dates. When the tool recognizes these types, it lists their categories without showing values and lets you download a copy with the matching blocks neutralized. Audio and video tracks are not re-encoded, but unknown fields may remain, so test the copy before sharing.

    Metadata is not an AI watermark

    Provenance credentials such as Content Credentials/C2PA describe how content was created or edited. If the tool finds a recognizable C2PA indicator, it stops instead of modifying the file. This check does not validate a credential or guarantee recognition of every provenance format.

    Invisible marks embedded in video pixels are part of the frames, not ordinary container metadata. This tool does not detect or remove them. It also does not erase visible text, logos, subtitles, or labels, and it cannot promise to change a platform’s classification.

    Privacy during processing

    Reading and creating the copy happen locally in your browser. The video is not uploaded to AI Content Cleaner for processing. The site does not read or record metadata values; optional analytics only records that the video tool was used if you consent.

    Frequently asked questions

    Will the video lose quality or audio?

    The tool does not re-encode audio or video tracks. It changes only recognized container fields. Still, check the copy in your target app and keep the original.

    Does this remove SynthID or make the video impossible to identify as AI?

    No. Marks embedded in video frames remain. The tool only cleans some common metadata and does not try to bypass detection, labels, or provenance credentials.

    Is the video uploaded to a server?

    No. The file is read and the copy is assembled in your browser. Video content and metadata values are not sent to AI Content Cleaner.

    Why might cleanup be blocked?

    If the scan finds a recognizable C2PA credential indicator, an advanced block it cannot inspect, or an incompatible structure, it will not create a copy. This helps avoid changing provenance data or producing a damaged file.

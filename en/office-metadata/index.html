    iSupported formats: DOCX, XLSX, and PPTX up to 15 MB. The tool does not remove comments, tracked changes, visible content, or every possible data location. Signed, protected, or macro-enabled files are not supported.

    What this Office cleaner changes

    DOCX, XLSX, and PPTX files can contain author, last editor, title, company, and other document properties. This tool inspects common core and application properties, removes recognized values, and creates a separate copy in your browser. The original document remains unchanged and is not uploaded to this site.

    Important limits

    This tool does not remove comments, tracked changes, visible text, hidden sheets or slides, embedded files, or every custom data location. It can only process supported Office Open XML files up to 15 MB. Macro-enabled, password-protected, digitally signed, older, or incompatible files are not supported; rewriting a signed document could invalidate its signature.

    How to use it

    1. Select a DOCX, XLSX, or PPTX file up to 15 MB.
    2. Review the common property types detected. Their values are not displayed.
    3. Download the cleaned copy and inspect it before sharing.

    For other formats, use the PDF metadata cleaner or tracked link cleaner.

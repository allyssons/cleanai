How to review image metadata

Photos can contain information beyond visible pixels. This guide explains what the tool can re-export, what it cannot inspect, and how to check the resulting copy.

What is image metadata?

Metadata is information attached to a file, such as camera model, date, orientation, and, when recorded, GPS location. The contents vary by device, app, and format; not every image contains every field.

Create a re-exported copy

Select a JPEG, PNG, or WebP within the limits shown in the tool. Your browser draws the image and saves a new copy without compatible metadata that is not preserved during re-export. The original is unchanged and is not uploaded for processing.

Review the image and downloaded file

Open the copy and check orientation, color, sharpness, and transparency. Re-exporting can change quality, color profile, or file size, especially for JPEG. If location is sensitive, inspect the copy with a trusted metadata viewer before sharing.

What cleanup does not do

It does not remove signs, faces, screens, documents, or other details visible in the pixels. It also does not promise to affect platform content labels. Other signals may be added after upload or inferred in other ways.

A careful workflow

  1. Keep the original in a safe place.
  2. Re-export a copy with the tool.
  3. Check visual quality and orientation.
  4. Inspect final metadata if location needs extra care.
  5. Share only the reviewed copy.

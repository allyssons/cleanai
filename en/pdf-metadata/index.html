Common fields found

Only field types are shown; their values stay private.

    iClear limits: the tool removes the PDF information dictionary and the root XMP packet when recognized. It does not remove visible content, forms, comments, attachments, watermarks, or every internal data location. Password-protected PDFs are not supported.

    What this PDF cleaner removes

    PDF files can store author, title, subject, keywords, software, and date fields. This tool checks the common document information dictionary and the root XMP metadata packet, then creates a separate PDF copy in your browser. Your original file is not modified or uploaded to this site.

    Important limits

    This is not a full forensic scrubber. It does not remove information visible on the page, form data, comments, attachments, watermarks, or every possible internal structure. Password-protected or incompatible PDFs may not open. Rewriting can invalidate digital signatures, which is why acknowledgement is required.

    How to use it

    1. Select a PDF up to 30 MB.
    2. Review the types of common fields detected. Values are never displayed.
    3. Acknowledge the signature warning and download the cleaned copy.

    For links and Office files, try the tracked link cleaner or the Office metadata cleaner.

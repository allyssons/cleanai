How to remove image metadata before sharing

Photos can carry more than the pixels you see. EXIF, GPS, camera details, and content credentials may travel with the file when you share it.

METADATA EXAMPLE

What may travel with a photo?

An image may include fields such as device model, date, and sometimes GPS coordinates. Cleanup creates a re-exported copy; it does not remove information visible in the pixels.

How to review a copy before sharing →

Original file

  • Camera model
  • Date and time
  • GPS, if present
→

Re-exported copy

  • Visible pixels preserved*
  • Compatible metadata omitted
  • Review the final file

*Re-exporting may change quality, color profile, or orientation. This is not an analysis of a real file.

What information can an image contain?

Depending on the camera and editing app, a photo may include EXIF, IPTC, or XMP information such as device model, capture date, GPS location, software name, and editing history. Some files also include Content Credentials based on C2PA, which describe content origin or edits.

This information can help organize and authenticate files. Before sharing, consider whether you want personal or origin details to travel with the image.

How the image cleaner creates a copy

  1. Choose one or more JPEG, PNG, or WebP images.
  2. The tool decodes each image in your browser and creates a new copy from its pixels.
  3. Download the re-exported file. Your original is not changed, and the image is not uploaded to our server.

When the browser creates a new image from a canvas, it does not carry over compatible original metadata. JPEG is recompressed, so quality, color, or file size may change slightly. Results can vary by browser.

Example: a photo before posting

A phone photo may contain a capture date and, if location was enabled, GPS coordinates even though none of that appears in the picture. The new copy is made from pixels and leaves out compatible metadata the browser does not preserve. Compare the JPEG appearance and size; if location is sensitive, review the downloaded file’s properties before posting. Keep the original until you finish checking.

What this cleanup does not do

It removes signals stored in file metadata. It does not remove watermarks embedded in pixels, such as SynthID, change the image to hide content, or identify who created it. A social network may use other signals or visual analysis, so we cannot guarantee that an AI label will disappear.

This version accepts JPEG, PNG, and WebP. HEIC, TIFF, and video are not supported by the image tool. Images over 40 MB or 40 megapixels are rejected to reduce the risk of running out of memory on your device.

Frequently asked questions

Does removing metadata erase a photo’s location?

The re-exported copy does not carry compatible GPS metadata that the browser does not preserve. Check the downloaded file before posting if location is especially sensitive.

Will the original file change?

No. The tool creates a cleaned copy and leaves the file you selected intact.

Will this remove an AI label on Instagram?

Not necessarily. The copy may omit credentials and tags that are not carried over when it is re-exported, but each platform may use other signals. We do not promise to remove or prevent labels.
